# River 快捷键速查

> 基于 `~/.config/river/init` 当前实际配置

## 常用

- `Super + Return`：终端（`footclient`）
- `Super + Space`：应用启动器（`fuzzel`）
- `Super + Q`：关闭窗口
- `Super + Shift + E`：退出 river
- `Super + T`：浮动开关
- `Super + F`：全屏开关
- `Super + Shift + Return`：当前窗口置顶 / zoom

## 焦点与交换

- `Super + J / K`：下一个 / 上一个窗口
- `Super + Shift + J / K`：与下一个 / 上一个窗口交换
- `Super + Period / Comma`：下一个 / 上一个显示器
- `Super + Shift + Period / Comma`：把窗口发到下一个 / 上一个显示器

## 布局（rivertile）

- `Super + H / L`：主区域比例 - / +
- `Super + Shift + H / L`：主区域窗口数 + / -
- `Super + Up`：主区域置上
- `Super + Right`：主区域置右
- `Super + Down`：主区域置下
- `Super + Left`：主区域置左

## 浮动窗口操作

- `Super + Alt + H / J / K / L`：左 / 下 / 上 / 右移动
- `Super + Alt + Ctrl + H / J / K / L`：吸附左 / 下 / 上 / 右
- `Super + Alt + Shift + H / J / K / L`：缩放窗口

## 工作区 / Tags

- `Super + 1..9`：切到 tag 1..9
- `Super + Shift + 1..9`：给当前窗口打 tag 1..9
- `Super + Ctrl + 1..9`：切换显示 tag 1..9
- `Super + Shift + Ctrl + 1..9`：切换当前窗口的 tag 1..9
- `Super + 0`：显示全部 tags
- `Super + Shift + 0`：当前窗口打上全部 tags

## 模式与鼠标

- `Super + F11`：进入 passthrough
- `passthrough` 下 `Super + F11`：回 normal
- `Super + 左键拖动`：移动窗口
- `Super + 右键拖动`：调整窗口大小
- `Super + 中键`：切换浮动

## 多媒体键

- `音量+ / 音量- / 静音`
- `播放暂停 / 上一首 / 下一首`
- `亮度+ / 亮度-`
